featurecallscache in / requestavg misssaved by cache
{{ r.route }}{{ "{:,}".format(r.input_tokens) }} in · {{ "{:,}".format(r.output_tokens) }} out {{ "{:,}".format(r.calls) }} {{ r.hit_rate }}% {{ "{:,}".format(r.per_request) if r.per_request is not none else '—' }} {{ "%.1f s"|format(r.avg_miss_ms / 1000) if r.avg_miss_ms is not none else '—' }} {{ "{:,}".format(r.saved) if r.saved else '—' }}

in / request divides input tokens by misses, not calls — a cache hit spends no tokens, so dividing by calls would make every prompt look cheaper as the cache warms. saved by cache is hits × the mean cost of a miss on that same route: an estimate, because the avoided prompt was never measured. A feature at 0% cache is paying full price on every request. avg miss is wall-clock per generated reading, per feature, and covers only days recorded since #355 — earlier days stored one global figure, so a feature with no recorded latency shows —, never 0. {% if ops.app.fallbacks %}The reasons beside needed a retry or a 2nd provider likewise cover only those days, so they can sum to less than the count. Only the last failure before the success is recorded, and a same-provider retry after a 429 counts as a fallback too.{% endif %}
